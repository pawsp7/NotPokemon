# Routewild (web / GitHub Pages build)

This folder is the **original browser game**, kept intact on the RPG Maker XP branch for reference and comparison.

Play locally:

```bash
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/`.

The live site is deployed from the `main` branch root (not this RMXP branch).
