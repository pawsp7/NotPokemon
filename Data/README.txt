Routewild Data folder
=====================

Scripts.rxdata is generated by:  ruby Tools/pack_scripts.rb

For all other .rxdata files (Actors, System, Map001, …), copy them from a
blank RPG Maker XP project so the editor can open Game.rxproj.

Gameplay does not use the default RMXP map/event database — it uses
Scripts/ + PBS/ instead. See ../README.md.
